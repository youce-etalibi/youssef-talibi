Scripto Buildo — No-Code Browser Automation Builder

Scripto Buildo is an internal automation platform I designed and developed at CMH to simplify the creation of browser automation scripts without requiring programming skills.

The application provides a visual drag-and-drop interface that allows users to build automation workflows by connecting predefined actions such as clicking, typing, navigating, waiting, and applying conditions.

Its main goal is to make browser automation accessible to non-technical users, reduce development time, and simplify repetitive tasks through visual workflow creation.

Key Features: No-code automation builder, drag-and-drop workflow editor, visual logic configuration, browser interaction automation, and script generation.

Warmix Agent Executor — Distributed Browser Automation Execution Engine

Warmix Agent Executor is an internal automation application I developed at CMH to receive and execute automation requests across multiple browsers and environments.

The application acts as an execution agent, processing remote requests and launching browser automation scripts using Selenium, Playwright, and Python. It enables automated task execution, process monitoring, and execution status reporting.

Its main goal is to support distributed automation, reduce manual intervention, and provide reliable script execution across multiple browser sessions.

Key Features: Remote script execution, multi-browser automation, Selenium & Playwright integration, task management, and execution status tracking.
